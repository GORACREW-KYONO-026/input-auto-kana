# 氏名自動カナ入力フォーム

このリポジトリは、React 19 + TypeScript + Vite で構築したシンプルな Web アプリです。氏名（漢字・ひらがな・ローマ字など）を入力すると、自動的にカタカナのフリガナ候補を生成し、必要に応じて手動で修正できます。

## 主な機能

- 氏名入力欄に文字を入力するとリアルタイムでカタカナを生成
- 自動変換がうまくいかない場合はフリガナ欄を直接編集可能
- 手動編集後もワンクリックで自動変換に戻せます

## セットアップ

```bash
npm install
```

## 開発サーバーの起動

```bash
npm run dev
```

ブラウザで [http://localhost:5173](http://localhost:5173) を開くとアプリを確認できます。

## ビルド

```bash
npm run build
```

ビルド済みのファイルは `dist/` に出力されます。

## 使用ライブラリ

- [React 19](https://react.dev/)
- [Vite](https://vitejs.dev/)

かな変換ロジックは外部ライブラリに頼らず、ローマ字・ひらがなからカタカナへの変換を独自実装しています。

## メモ

漢字から正しいフリガナを推測することは難しいため、漢字で入力した場合は変換結果を手動で修正することを想定しています。入力途中での読み仮名は IME を通じて取得できるため、ひらがなやローマ字の入力でもご利用いただけます。
